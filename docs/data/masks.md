# Masks

**Positional validity mask** contracts for **v0.1.0a8**.

Optional boolean `mask_npy` on train/val profile payloads marks retained
positions eligible for position-wise losses and metrics. Forbidden on test
payloads.

See [Glossary](../reference/glossary.md), [Profiles](../profiles.md), and
[Profile masks workflow](../workflows/profile-masks.md).
