# Splits

Train, validation, and test split contracts for **v0.1.0a8**.

- Train and tune configs require `train_data` and `val_data`
- Prediction configs require `test_data`
- Split blocks share encoder and loader keys; label requirements differ

See [Config](../config.md) and [Formats](../formats.md).
